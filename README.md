# Lightweight AI-Based Jamming Attack Detection

This repository contains the official Python code for the article:

**[A Lightweight AI-Based Approach for Drone Jamming Detection](https://www.mdpi.com/1999-5903/17/1/14)** *Future Internet*, 2025, 17(1), 14.  
DOI: `10.3390/fi17010014`

---

## Overview

This project implements an unsupervised anomaly detection system to identify jamming attacks in 6G-enabled drone networks. The solution is designed to be lightweight and suitable for resource-constrained devices.

The core algorithm is a tuned **Isolation Forest (IF)** model combined with a **Majority Rule (MR)** module to enhance detection accuracy and reduce false positives.
